Основная часть
Основная часть. Задание 1.
1.a. Перекрёстная проверка с исключением одного наблюдения — это метод, при котором на каждом этапе для проверки выделяется только одно наблюдение. Если у нас N наблюдений, то обучение выполняется N итераций на N-1 выборке. Результирующая метрика представляет собой среднее значение N метрик. Преимущества: мы многократно подгоняем модель к набору данных, содержащему N-1 наблюдение, чтобы уменьшить переобучение. Недостатки: это трудоёмкая процедура для больших N.
1.b. Поиск по сетке принимает заданные вручную диапазоны параметров в качестве входных данных и тщательно ищет наилучшую комбинацию. Случайный поиск перебирает случайные комбинации гиперпараметров для нахождения наилучшего решения. Байесовская оптимизация позволяет оптимизировать f(x), то есть производительность модели, где x — заданные гиперпараметры.
1.c. Метод Пирсона использует корреляционную матрицу и позволяет отбрасывать признаки с корреляциями, близкими к 1. Значение хи-квадрат показывает зависимость между признаками и откликом. Чем ниже значение хи-квадрат, тем слабее зависимость. Лассо как метод регуляризации отображает признаки с коэффициентом = 0, что означает, что такие признаки можно отбросить. Важность перестановки рассчитывается после подгонки модели. Затем значения признаков случайным образом перемешиваются. Затем мы измеряем качество модели с таким признаком и оцениваем его влияние.
